## Things I've built

**[hack-computer](https://github.com/Ahm3dGI1/hack-computer)** — `HDL` `Python` `Jack`
A working computer from a single NAND gate up: 30+ logic chips, an ALU and CPU, a two-pass assembler, a VM translator, a Jack compiler with a recursive-descent parser, and an OS standard library. Nothing borrowed from an abstraction layer I hadn't already built.

**[hermex](https://github.com/Ahm3dGI1/hermex)** — `FastAPI` `Whisper` `React` `TypeScript` `Firebase`
Turns a video into an interactive lesson. A Python pipeline transcribes and summarizes, then generates comprehension checkpoints; the React player injects them at the right timestamps rather than dumping a quiz at the end.

**[gofi](https://github.com/Ahm3dGI1/gofi)** — `Rust` `egui`
A keyboard-first file finder. Persistent binary cache, search on a background worker so the UI never blocks, and depth-penalized fuzzy ranking — because the file you want is usually not eight directories deep.

**[3D-Physics-Engine](https://github.com/Ahm3dGI1/3D-Physics-Engine)** — `C++` `OpenGL` `GLSL`
Rigid body dynamics and cloth simulation over a hand-rolled vector/matrix/quaternion library. AABB for orientation-fixed collisions, SAT for everything that rotates. Instanced rendering to keep 10,000+ particles interactive.

**[Private-Desktop-AI-Assistant](https://github.com/Ahm3dGI1/Private-Desktop-AI-Assistant)** — `Electron` `React` `Python`
Built with Adobe as a partner. The interesting part is a JSON-based tool-calling framework that chains actions across Calendar, Gmail, and GitHub from a single prompt — this was before function calling was a solved problem.
